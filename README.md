# ASHKB · 强直性脊柱炎个人健康管理 App

Ankylosing Spondylitis Health Knowledge Base —— 一款面向强直性脊柱炎（AS）患者的**离线优先**个人健康管理应用。不联网、无账号、数据全部本地存储，围绕「用药—症状—运动—复诊」日常闭环设计。

> ⚠️ **免责声明**：本应用为个人健康管理记录工具，不构成任何医疗建议，不能替代医生诊疗。用药与治疗方案请始终遵医嘱。

## 功能总览

### 💊 今日（用药与打卡）
- 药单管理：口服 / 注射（含每两周、每周、**每周两次**如恩利 25mg×2/周、自定义周期），多种频次计划槽位
- 今日用药卡一键打卡：口服（餐前/餐后）、注射（部位轮换 / 批次号）、PRN 按需记录
- 精确闹钟提醒：开机、时区/系统时间变更、权限回授自动重排，late 容错判定不影响依从统计
- 用药核对清单（R03）：添加药品时按「通用名键 + 药物类别」自动检索内置知识库，给出红黄药警示与忌口提示
- 通用名键自动匹配：输入中英文（键 / 通用名 / 商品名 / 别名）实时建议，一键回填

### 🩺 健康（体征 / 营养 / 复诊 / 紧急）
- 体征记录：血压、心率、体温、血氧、血糖
- 体重与围度追踪、补剂档案（剂量 / 频次 / 活性状态）
- 饮食画像与忌口清单（促炎 / 过敏 / 不耐受食物）
- 复诊管理：复诊项目周期配置、复诊记录、化验结果（参考范围 + 异常标记，点偏高/偏低胶囊即展开该指标参考范围）、影像记录（MRI / CT / X 线）、疫苗记录（活疫苗 × 生物制剂强制医生确认）
- 检查报告 AI 导入：复制内置模板连同报告照片发给任意 AI 助手，AI 按格式整理后粘贴回 App 自动解析入库（化验单 + 影像报告，App 本身不联网、不上传照片）
- 紧急卡：五应急场景卡（葡萄膜炎 / 感染发热 / 骨折 / 胃肠道急症 / 生物制剂不良反应）、120 快拨、紧急联系人一键呼叫、个人急救信息卡（可导出打印版 PDF）

### 📊 报表
- 30 天服药依从率（完成 / 部分 / 跳过）、运动执行、症状均值、BASDAI 评分走势与活动度阈值（≥4.0 警示）
- 自绘趋势图：BASDAI / 疼痛 / 晨僵 / 体重 / 血压 / 心率
- 复诊报告 PDF 导出（档案 + 用药 + 依从症状 + 化验复诊 + 下次复诊），系统分享面板分发

### 🏃 运动（R27 分级矩阵）
- 按疾病分期（缓解期 / 控制中 / 发作期；未评估按发作期保守处理）与脊柱活动度判读，输出当日运动处方；发作期红榜 L2/L3 一律暂停，当日只出 L1 轻柔项
- 黑榜动作拦截（如颈椎高风险动作全期拦截），运动后反馈记录；昨日疼痛 / 晨僵 / 体温作为处方参考展示

### 📚 知识库
- 内置种子医学知识（指南共识摘要、相互作用、忌口、疫苗、应急场景），本地检索，无需联网

### 👤 我的（备份与数据自主）
- **加密备份**：AES-256-GCM + PBKDF2 口令派生，逐表 SHA-256 清单校验，恢复前自动快照可撤销，备份台账全记录
- **WebDAV 云备份**：零依赖自实现（探针 / 上传回读比对 / 保留策略轮换）；备份文件名带时间戳（同天多份不互相覆盖），换新机登录同一账号后可直接拉取服务器备份列表选择恢复，无需先生成本地备份
- 档案 JSON 明文导出 / 导入（换机建档）

## 技术栈

| 项 | 说明 |
|---|---|
| 语言 / UI | Kotlin · Jetpack Compose（Material 3） |
| 存储 | Room（v9，含 1→9 链式迁移，25 实体表） |
| 依赖 | **仅 AndroidX / Kotlin 官方库**，零第三方 UI / 网络 / 图表库 |
| 图表 | Canvas 自绘折线图 |
| PDF | `android.graphics.pdf` 原生导出 |
| 加密 | `javax.crypto` AES-256-GCM + PBKDF2（备份容器） |
| 架构 | 单模块 MVVM（ViewModel + Repository），domain 层纯函数可测 |
| SDK | compileSdk 34 · minSdk 26（Android 8.0+） · targetSdk 34 |

## 构建

```bash
git clone https://github.com/weante/ashkb.git
cd ashkb
gradle assembleDebug        # Debug APK
gradle assembleRelease      # Release APK（注意：签名配置请自行修改）
gradle testDebugUnitTest    # 单元测试
```

> ⚠️ 本仓库**不含 Gradle wrapper 脚本**（`gradlew` / `gradlew.bat` / `gradle-wrapper.jar` 均未入库，
> 仅保留 `gradle/wrapper/gradle-wrapper.properties` 作为版本声明），所以上面用 `gradle` 而非 `./gradlew`。
> 请使用 **Gradle 8.7**；或直接用 Android Studio 打开（会自行接管构建）。

要求：JDK 17+、Gradle 8.7、Android SDK 34。

## 数据与隐私

- **无网络权限需求**（仅 WebDAV 备份时使用，需手动配置）；无任何埋点、统计、账号体系
- 所有健康数据仅存于本机 Room 数据库
- WebDAV 远程备份**强制 HTTPS**：明文 http 地址一律拒绝——明文传输会把账号密码暴露给链路上任何人
- 备份文件为加密容器：口令不落盘，AAD 绑定防篡改，恢复走「解密自校验 → 快照 → 事务覆盖 → 行数+SHA 双校验 → 台账」五步

## 测试

386 条 JVM 单元测试覆盖核心 domain 逻辑：排程计算（含 BIW 每周两针边界、ISO 时刻取「时刻」的展示口径、槽位标签 = 计划时刻、时间选择器初始值的容错解析）、提醒链「取消-重建」语义（Robolectric + `AlarmManager`）、炎症指标（ESR / CRP）名称归一（不做模糊匹配）与单位换算（`mg/dL`→`mg/L`）、化验行→序列的三类口径（单位、窗口、同日去重）、小多图共享时间轴（日期并集窗口与窗口相对坐标）、运动分级矩阵 R27（三态分期 + 发作期 L1 兜底）、检查报告 AI 导入解析（化验 / 影像 / 参考范围 / 未识别行提示）、备份加密（v1/v2/v3 三格式互读 + 恢复码 + 稳定密钥 + 附件密文）/ 恢复表名与列名白名单及 SHA / WebDAV 远程列表解析与轮换保留 / 附件远端路径口径（含百分号编码绕过）、知识库检索口径（单列检索文本 + 中文子串语义）与种子增量刷新判定、趋势图坐标口径（按日期真实间隔定位 / 跨年 / 脏日期回退 / 刻度间隔数受可用高度约束 / 阈值必入量程 / 拖动命中与绘制定位一致 / 读数摘要）、紧急卡用药汇总（免疫抑制类判定）、漏服处理指引（口服补服窗口 / 注射超窗分级）、体重目标区间判定、复诊准备清单、通用名键目录、服药依从口径（部分完成按 0.5 计 / 无记录不算完全依从，报表与药单「用药记录」共用同一实现）、用药记录手动修正的不变量（已服不留原因 / 部分·跳过必填原因 / 部位仅已服有意义）与注射部位存库键稳定性、崩溃留档凭据脱敏、源码正则花括号静态守卫（含未覆盖形态告警）。
