#

# 本文件由 convert.js 从生成器输出**直接转换**而成，不经任何手工转录——转录

#
# 唯一例外：tag65 组的 tag_hex 来自 Node.js v24 内置的 crypto.argon2Sync
# （OpenSSL C 实现）。原因：@noble/hashes 1.7.1 的 Hp() 末尾是 `return u32(out)`，
# 而 u32() 是 `new Uint32Array(buf, off, floor(len/4))`，对 65 字节会截掉最后
# 一个字节、只返回 64 字节——这是参考实现自身的缺陷，不是 RFC 语义。该组已用
# Node 内置实现交叉验证：noble 返回的 64 字节与 OpenSSL 返回的前 64 字节完全
# 一致，第 65 字节为 0x24。两个独立实现互证，不是本仓库代码产物。
#
# 格式：每个 case 以 [case name] 开头，随后若干 key=value，以 tag_hex 结束。
